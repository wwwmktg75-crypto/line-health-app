# line-health-app — LINE健康記録アプリ

家族の服薬や体調を、**普段使っている LINE で送るだけ**で記録できるアプリです。

記録する人（たとえば高齢の親御さん）は、新しいアプリを覚える必要はありません。
LINE 公式アカウントに「朝の薬飲んだ」「血圧 128/82」のように送ると、内容に応じて
自動で種類分けして保存し、確認の返事が届きます。見守る家族は、パスワード付きの
管理画面で記録や薬の残り日数を確認できます。

もともと「心臓の病気で毎日薬を飲む父のために、娘が作った」という実用アプリを、
誰でも自分の Cloudflare アカウントで運用できるように公開したものです。

## 主な機能

- **服薬記録（毎日の薬）**: 「朝の薬飲んだ」と送るだけで、その日の朝の薬をまとめて記録
- **服薬記録（随時の薬）**: 寝る前に飲む薬などは、薬の名前を送ると記録し、登録した個数から1個減らします
- **薬の残量管理**: 毎日の薬は「処方日数」と「服用開始日」から残り日数を自動計算
  （押した回数で数えないので、二度押しや押し忘れで狂いません）。
  「薬あと何日」と送ると、全ての薬の残り日数・個数をまとめて返信します
- **バイタル記録**: 血圧（`血圧 128/82`）、体温（`体温 36.5`）、体重（`体重 62kg`）を文章から自動判別
- **体調・生活メモ**: 数値に当たらない文章（例:「腰が痛い」）はメモとしてそのまま保存
- **毎朝8:30のリマインダー**: 毎朝8:30（日本時間）に「おはようございます。朝のお薬は
  飲みましたか？」と、［朝の薬飲んだ］［薬あと何日］の**クイックリプライボタン付き**で
  プッシュ送信します。その日の朝の薬が記録済みの人には送りません
- **管理画面**: 今日の記録タイムライン、薬の一覧と残り日数（±調整つき）、記録の手動追加。
  パスワードログインで保護
- **記録一覧ページ**: 過去の記録を日付ごとに表示し、種類で絞り込み可能。
  LINE のリッチメニューのボタンからも開けます
- **リッチメニュー**: 画面下の大きなボタン（薬飲んだ／体調／薬の残り／記録を見る）で、
  文字入力が苦手でもタップだけで記録できます

## 技術構成

| 要素 | 内容 |
| --- | --- |
| 実行環境 | Cloudflare Workers（`src/index.js`、外部依存ゼロ・単一ファイル） |
| データ保存 | Cloudflare D1（SQLite）— テーブルは `records` / `meds` / `users` |
| 連携 | LINE Messaging API（Webhook 受信・署名検証つき / Reply API / Push API） |
| 定期実行 | Cloudflare Cron Triggers（毎朝8:30 JST = `30 23 * * *` UTC） |
| 時刻 | すべて Asia/Tokyo で処理 |

料金面では、Cloudflare の無料枠と LINE 公式アカウントの無料プランの範囲で
運用できる規模を想定しています（朝のリマインダーは1日1通×人数分）。

## セットアップ手順

### 1. LINE 公式アカウントと Messaging API チャネルを作る

1. [LINE公式アカウントマネージャー](https://manager.line.biz/) で公式アカウントを作成
2. そのアカウントの「設定 → Messaging API」で「Messaging APIを利用する」を押し、
   プロバイダーを作成（または選択）してチャネルを有効化
3. [LINE Developers コンソール](https://developers.line.biz/console/) でそのチャネルを開き、
   - 「チャネル基本設定」の **チャネルシークレット** を控える
   - 「Messaging API設定」で **チャネルアクセストークン（長期）** を発行して控える

### 2. Cloudflare アカウントと D1 データベースを用意する

1. [Cloudflare](https://dash.cloudflare.com/) にアカウントを作成
2. API トークンを発行する（My Profile → API Tokens →「Cloudflare Workers を編集」テンプレート。
   D1 をスクリプトから作りたい場合は D1 の編集権限も追加）
3. アカウント ID を控える（Workers & Pages の概要ページに表示）
4. （任意）Workers & Pages → D1 で、名前 `line-health-app` のデータベースを作成し、
   データベース ID を控える
   - テンプレート権限のみのトークンでは D1 を API から作れないため、その場合は
     この手動作成＋後述の `--d1-id` 指定が確実です

### 3. デプロイする

Node.js（テスト用）と Python 3（デプロイスクリプト用）が必要です。

```bash
# シークレットファイルを作成（値は自分のものに書き換える。git 管理外です）
cp secrets.local.example.json secrets.local.json

export CLOUDFLARE_API_TOKEN="<発行したAPIトークン>"
export CLOUDFLARE_ACCOUNT_ID="<アカウントID>"

# まずドライランで計画を確認
python3 deploy_personal.py

# 実行（手順2で D1 を手動作成した場合は --d1-id と --skip-schema を付ける）
python3 deploy_personal.py --yes --d1-id <データベースID> --skip-schema
```

成功すると公開 URL と Webhook URL が表示されます。
（Worker は初回アクセス時にテーブル作成とサンプル薬の登録を自動で行うため、
`schema.sql` の適用は省略しても動作します。）

コードだけを更新して再デプロイする場合は、シークレットを引き継ぐ安全な方法があります:

```bash
python3 deploy_personal.py --yes --inherit-bindings
```

### 4. シークレット（4つ）を設定する

以下の4つが Worker のシークレットです。`secrets.local.json` 経由でデプロイ時に
設定されます。デプロイ後に Cloudflare ダッシュボード
（Workers & Pages → line-health-app → 設定 → 変数とシークレット）で直接追加・変更もできます。

| 名前 | 内容 |
| --- | --- |
| `LINE_CHANNEL_SECRET` | LINE チャネルのシークレット（Webhook の署名検証に使用） |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE チャネルのアクセストークン（長期） |
| `ADMIN_PASSWORD` | 管理画面のログインパスワード（自分で決める） |
| `HISTORY_TOKEN` | 記録一覧ページの URL の鍵（ランダムな長い文字列を自分で作る） |

これらの値は **絶対に git にコミットしないでください**（`secrets.local.json` は
`.gitignore` に含まれています）。

### 5. Webhook を設定する

1. LINE Developers コンソールの「Messaging API設定」で、Webhook URL に
   `https://<あなたのWorkerドメイン>/webhook/line` を設定
2. **「Webhookの利用」を ON** にする
3. LINE公式アカウントマネージャーの「設定 → 応答設定」で、
   **あいさつメッセージ：OFF / 応答メッセージ：OFF** にする
   （ON のままだと、アプリの返信と自動返信が二重に届きます）
4. 自分の LINE でアカウントを友だち追加し、「血圧 128/82」と送って
   確認の返事が来れば連携成功です

### 6. リッチメニューを適用する

1. メニュー画像（2500×1686 px）を用意します。4つのボタン領域に
   「💊薬飲んだ」「❤️体調」「💊薬の残り」「📋記録を見る」の文字を描いた画像にしてください
2. `richmenu.json` の `<your-worker-domain>` と `<HISTORY_TOKEN>` を自分の値に書き換えます
3. `richmenu-note.md` の手順（作成 → 画像アップロード → デフォルト設定）で適用します

### 7. 朝のリマインダー（Cron）を有効にする

```bash
python3 deploy_personal.py --yes --set-schedule
```

毎朝8:30（日本時間）に、その日の朝の薬が未記録のユーザー全員へ、
ボタン付きメッセージをプッシュ送信するようになります。
時刻を変えたい場合は `deploy_personal.py` の `SCHEDULE_CRONS`（UTC 表記）を変更してください。

## 薬データをカスタマイズする

薬の初期データは **`src/index.js` の `SEED_MEDS`** にあります（`schema.sql` にも同じ内容）。
リポジトリ内のデータはすべてサンプルです。実際に使う前に、ご自身の処方に合わせて書き換えてください。

- 毎日の薬: `kind: "daily"`、`timing`（飲み方）、`total_days`（処方日数）、
  `start_date`（服用開始日。先頭の `SEED_START_DATE` 定数を実際の開始日に変更）
- 随時の薬: `kind: "asneeded"`。名前で記録できるよう、**`AS_NEEDED_MEDS`**（エイリアス一覧）
  にも同じ名前を登録してください
- 残りの個数は、管理画面から後で登録できます

すでに運用を始めた後に薬が変わった場合は、D1 の `meds` テーブルを直接編集するか、
一度データベースを作り直してください（シードは `meds` テーブルが空のときだけ動きます）。
